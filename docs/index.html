Características Principais

Alta Performance

Implementação otimizada para máxima eficiência, utilizando componentes nativos em C e técnicas avançadas de otimização.

Bash como Orquestrador

Utiliza o poder do Bash para gerenciar e orquestrar componentes, aproveitando o que ele faz de melhor: gerenciamento de processos.

Componentes em C

Workers e banco de dados implementados em C puro para máxima eficiência e controle sobre recursos.

Banco In-Memory

Banco de dados em memória com persistência via snapshots, otimizado para operações de alta velocidade.

Balanceamento de Carga

Nginx configurado para distribuição eficiente de requisições entre múltiplos workers.

Auto-Healing

Recuperação automática de falhas, garantindo alta disponibilidade e resiliência do sistema.

Bash Orchestrator

Responsável por iniciar, monitorar e gerenciar todos os componentes do sistema. Implementa recuperação automática de falhas e gerencia o ciclo de vida dos processos.

Nginx Load Balancer

Distribui requisições entre múltiplos workers, configurado para máxima eficiência com número reduzido de workers e implementa keep-alive para reduzir overhead de conexão.

C Workers

Servidores HTTP leves implementados em C puro que processam requisições REST e implementam a lógica de negócio, comunicando-se com o banco de dados via protocolo TCP personalizado.

In-Memory Database

Banco de dados em memória implementado em C que utiliza estruturas de dados otimizadas para busca e inserção, implementa persistência via snapshots periódicos e suporta recuperação de dados após reinicialização.

Estratégias de Otimização

  • Redução de Overhead de Rede

    Uso de network_mode: host para comunicação direta entre componentes, eliminando a camada de virtualização de rede do Docker. Implementação de protocolo de comunicação binário entre worker e banco para máxima eficiência.

  • Otimização de Memória

    Alocação estática para evitar fragmentação, estruturas de dados compactas e reuso de buffers para evitar realocações frequentes, reduzindo a pressão sobre o garbage collector.

  • Otimização de CPU

    Algoritmos de busca otimizados utilizando hash tables, processamento em lote (batch) para inserções e compilação com flags de otimização (-O3) para máximo desempenho.

  • Persistência Eficiente

    Snapshots incrementais em background e journaling para operações críticas, garantindo durabilidade sem comprometer a performance do sistema.

  • Balanceamento de Carga

    Configuração otimizada do Nginx e número de workers ajustado para máxima eficiência, considerando as limitações de recursos da Rinha (1,5 CPU e 3GB RAM).
